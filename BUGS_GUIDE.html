After fixing ingestion: the re-ingest checklist

  1. Put a valid OPENAI_API_KEY in .env and confirm with a one-line embedding call.
  2. Fix bugs 2, 3 and 4 (failure reporting, deterministic IDs, chunker threshold).
  3. Run python -m app.ingestion.processors DATA --wipe so the collection is rebuilt cleanly.
  4. Compare processed_data chunk totals with the Qdrant point count: they should now match.
  5. Ask three real questions in the UI and confirm the sources are relevant and cited.
